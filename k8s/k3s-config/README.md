# K3s configuration

Nothing here yet. K3s's configuration on each node is generated by the
installer rather than kept as files:

- the server flags — flannel, network policy and the packaged Traefik
  and ServiceLB off, and kube-proxy too when Cilium is set to replace
  it, since Cilium does their jobs; and the OpenID Connect flags
  Headlamp's sign-in needs — in
  `installer/src/cli/commands/K3s.ts`
- `/etc/rancher/k3s/registries.yaml`, from `registries` in the
  configuration, written by the `registries` bundle
  (`installer/src/cli/commands/Registries.ts`)

See the [installer README](../../installer/README.md#k3s).
